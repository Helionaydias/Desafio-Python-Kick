# Projeto Python - Análise de Bolsas

Este projeto realiza uma análise sobre a distribuição de bolsas em diferentes regiões, tipos e gêneros. Utiliza gráficos e dados para visualização, ajudando a entender padrões e tendências nas bolsas oferecidas.


## Como Instalar
1. Clone este repositório para o seu computador:
   ```bash
   git clone https://github.com/usuario/projeto-python.git
   ```
2. Instale as dependências necessárias:
   ```bash
   pip install -r requirements.txt
   ```

   ## Como Usar
O projeto contém um notebook Jupyter, `projeto_python.ipynb`, onde são realizadas as análises e gerados os gráficos. Abra o notebook e execute as células para ver os resultados.

## Funcionalidades
- Análise de bolsas por região, tipo e gênero.
- Gráficos de distribuição de bolsas.
- Comparação entre bolsas integrais e parciais.

## Dependências
- pandas
- matplotlib
- seaborn
- jupyter
